AI Engineer · Technical Assignment

Invoice‑to‑Payment.
Automated.

An AI agent that reads invoices, matches them to purchase orders, and posts payments — with human oversight where it counts.

The problem

Accounts Payable
still runs on manual effort.

Invoices arrive as PDFs, scans, and email. — no schema.
Every one is matched to a PO by hand. — line by line.
Variances and duplicates need judgement. — and an audit trail.
The idea

Meet the agent.

It does the reconciliation. People handle the exceptions.

The flow
Ingest→ Extract→ Match→ Post/ Escalate→ Audit

One pipeline, end to end — mirrored for AR remittances.

Foundations

Built on a proven stack.

Docling document AI PGVector + LlamaIndex LangGraph orchestration Ollama local LLM Phoenix observability RAGAs evaluation FastAPI · Docker
Architecture

Five services. One command.

Agent API· Mock ERP· Postgres + PGVector· Ollama· Phoenix

The agent orchestrates; Docling parses; Ollama reasons; LlamaIndex retrieves; the ERP posts; Phoenix watches.

Data

Data you can trust.

A seeded generator builds invoices from real POs across every scenario — each one self-labelled for evaluation.

Ingestion

Read the mailbox.
Any format.

Provider-abstracted intake — Microsoft Graph, Gmail, or folder replay — extracting, classifying, and de-duplicating every attachment.

Extraction

Turn a document
into structured data.

Docling parses; a local LLM returns schema-validated fields; a deterministic backstop recovers what the model misses.

It reads scans, too.

Born-digital PDFs use the text layer. Image-only scans fall back to OCR — automatically.

Retrieval

Find the right PO —
even when the invoice is messy.

Semantic search over PO embeddings in PGVector shrugs off fuzzy vendor names and missing PO numbers.

100%
retrieval hit@1 · MRR 1.0

The correct purchase order, ranked first — every time, across fuzzed-vendor tests.

Matching

2‑way. 3‑way.
Tolerant by design.

Line-level comparison against PO and Goods Receipt, with configurable price and quantity tolerances.

Orchestration

One graph.
Every step.

A LangGraph state machine routes clean matches to auto-posting and everything else to a human — accumulating an audit trail along the way.

Human-in-the-loop

Automation with
a safety net.

Exceptions queue for review. Approve to post the journal. Reject to close. Always audited.

Closing the loop

Both directions.

Payable

Post an approved invoice as a Payment Journal — idempotent, so duplicates never pay twice.

Receivable

Match inbound remittances to open AR items and apply cash — full, partial, or overpaid.

Trust

Every decision,
traceable.

One audit record per step, correlated across a run and linked back to the source email.

Observability

See inside the agent.

OpenTelemetry traces stream to Arize Phoenix — the retrieval and reasoning steps, visible.
